# EDA Лаборатория

Интерактивно учебно приложение за предварителен анализ на данни (Exploratory Data Analysis) и подготовка на данните за анализ.

## Съдържание

**I. Предварителен анализ (диагноза, данните не се променят)**
- 1.1 Преглед на данните: речник на данните, таблица с откриване на проблемите (режим „Студент“ / „Преподавател“)
- 1.2 Качество на данните: липсващи стойности, грешки, дубликати, екстремни стойности, нерелевантни признаци
- 1.3 Описателни статистики: централна тенденция, разсейване, форма; изчисляване стъпка по стъпка
- 1.4 Разпределения: хистограма, кутийна диаграма, Q-Q диаграма, тест на Жарке–Бера, галерия на формите
- 1.5 Взаимовръзки и класове: scatter, корелационна матрица, scatter matrix, разпределение по класове
- 1.6 Протокол на констатациите

**II. Подготовка на данните (лечение, ефект „преди / след“)**
- 2.1 Почистване в пет стъпки с избор на метод
- 2.2 Трансформации: обединяване, агрегиране, мащабиране, степенни трансформации, кодиране, дискретизация, нов признак, редуциране на размерността (подбор на признаци и PCA)
- 2.3 Резултат: сравнение, сваляне на CSV и на скрипт на Python

Превключвателят „Сурови / Почистени“ в Част I показва всяка статистика и диаграма и върху почистените данни, с методите, избрани в 2.1.

## Технически бележки

- Статичен сайт: HTML, CSS и JavaScript без външни библиотеки и без стъпка за изграждане. Всички диаграми са SVG.
- Работи и при директно отваряне на `index.html` от диска.
- Наборът от данни се генерира с фиксирано начало (seed), затова е еднакъв при всяко отваряне.
- Формулите съвпадат с pandas по подразбиране (дисперсия с n − 1, квантили с линейна интерполяция, коригирани скосеност и ексцес). Проверено срещу pandas и scikit-learn.
- Шрифтът IBM Plex се зарежда от Google Fonts; без интернет се използва системен шрифт.

## Структура

```
index.html
css/style.css
js/util.js        форматиране
js/stats.js       статистически функции, PCA
js/data.js        речник на данните и набор от данни
js/quality.js     откриване на проблемите
js/pipeline.js    почистване и трансформации
js/charts.js      SVG диаграми
js/app.js         навигация и състояние
js/pages/         страниците на двете части
vercel.json
```

## Публикуване във Vercel

**Чрез GitHub**
1. Качете папката в ново хранилище в GitHub.
2. Във Vercel: Add New → Project → изберете хранилището.
3. Framework Preset: **Other**. Build Command: празно. Output Directory: празно (коренът).
4. Deploy.

**Чрез командния ред**
```
npm i -g vercel
cd eda-lab
vercel          # предварителен преглед
vercel --prod   # публикуване
```

## Локално

Отворете `index.html` в браузър или стартирайте локален сървър:
```
npx serve .
```
